The MatchesWeb Project

Introduction

The MatchesWeb project is an illustration of various ways in which to implement the Matches Game. This is a quick introduction as to how to service a web page

The Matches Game

The Matches Game is a game which starts off with 25 matches. Two Players play alternately, and may pick up 1,2,3 or 4 matches on their turn. The player who cleans up the matches, leaving no more for his opponent, wins.

The strategy to win the game is based on the observation that the player who gets 5 matches cannot win. No matter what he takes, the other player can take the rest and win. Then clearly, the player who gets 10 matches cannot win, for then his opponent can reduce him to 5 matches, and then win. Following this logic, the player who gets a multiple of 5 matches, say 10, 15, 20 or 25 cannot win, for then his opponent can force him to be left to play with the next lower multiple of 5. Repeated application of this strategy by one player reduces the other player to always face a whole multiple of 5 matches, leading finally to 0 matches and lose.

When the user plays against the computer as the opponent, the strategy is therefore to present the user with a multiple of 5. The computer must pick up the remaining-matches%5 (% is the remainder-modulo-5 operator), to reduce the remaining-matches to the next lower multiple of 5.

Matches Game using JavaScript Only

The JavaScript only technology uses JavaScript to implement the game strategy algorithm. This is straightforward JavaScript that reads the values of various HTML tags, computes the next move, and then updates the HTML tags appropriately.

The html elements are described below

  • The script has JavaScript code for the play() function and the clearDisplay() function. The play() button is invoked when the user clicks the button with id tag "playButton". The clearDisplay is invoked when the user clicks the button with id tag "clearButton".
  • The textarea tag with id "display" is where the system prints messages regarding its play choice, or to indicate errors. It is set to automatically scroll as needed.
  • The input tag with id "matches" is the text input field. It specifies the number of matches remaining.
  • The select tag with id "taken" is the drop-down list that indicates the user's choice for his move.
  • The button tag with id "playButton" is the button the user presses to submit his play choice. When clicked it invokes the play() function
  • The button tag with id "clearButton" is the button the user presses to clear the display area "display"

The play() button reads the value of the user play choice in the drop down selection list, the JavaScript variable "taken". It then executes the game logic to determine the value of the system move in the JavaScript variable "newTaken". It then updates the "matches" input field, and the "display" textarea.

The code is in MatchesWeb_JS_Only.html and can be examined in a text editor.

Matches Game using Web Servers

The rest of the techniques use web servers. The html file is MatchesWeb_JS_WebServer.html. After the web server is started up, the web browser should be targeted at the appropriate URL specified in this documentation. The web browser need not be on the same system as the Web Server.

The html file uses JavaScript to send a JSON (JavaScript Object Notation) data structure message to the web browser. This JSON message string has the form:

{"matchesRemaining" : "25", "taken" : "2"}

The message is sent to the web server using AJAX (Asynchronous JavaScript and XML) technnology for updating parts of a webpage without a full reload. It uses AJAX with the jQuery library which provides a user-friendly, cross-browser compatible wrappingaround AJAX. Details about using this technology can be found at The jQuery ajax() function.

Matches Game using Apache server with PHP

In this technology, we need 2 files, the JavaScript HTML file MatchesWeb_JS_WebServer.html, and the server PHP file MatchesWeb.php. The web server must be accessible as an URL. For the purpose of this document, we will assume the URL for the web server is http://192.168.1.64. Any IP address or Domain Name where your server is available can be substituted.

The web browser should be targeted at URL http://192.168.1.64/MatchesWeb.php (or else at your own domain-name followed by "/MatchesWeb.php").

If you have your own web server, then MatchesWeb.php needs to be installed at the Document Root directory for your server. With Apache httpd server, this is /var/www/html on the server machine. For this, the Apache Web Server (or other web server) needs to be installed on some machine accessible from your web browser machine.

Firewall enablement for Experimental Web Servers

When you use a web server from a commercial vendor, the server machine firewall is properly configured to accept requests on a port (usually port 80). If you install the Apache server on your own machine, it too configures the firewall to accept requests appropriately.

However, when you build your own experimental web servers, as we will be for the remaining technologies, it is necessary to set up the firewall appropriately. As we will be configuring our experimental servers to use port 8080, it is necessary to enable the port for requests from other machines prior to starting up the server. Finally, when the experiment is complete, it is necessary to disable the port to keep your server machine secure. To this end you should use the following commands:

  1. On the server machine, as super-user, do this command before starting the experimental server:

    netstat -a | grep :8080

    There should be no output. The port 8080 should be unused.
  2. Then, do the following command to enable port 8080:

    firewall-cmd --add-port=8080/tcp

  3. Finally after the experiment, do the following command to disable port 8080:

    firewall-cmd --remove-port=8080/tcp

Matches Game using Python Flask Web Server

In this technology, you will also use the JavaScript HTML file MatchesWeb_JS_WebServer.html. You will need to install the Python Flask framework on your system. This can be done by the command:

pip3 install flask

Once that is done, you will be able to execute the program MatchesFlask.py by the command

python3 MatchesFlask.py

The program will supply the URL to connect the web browser to.
